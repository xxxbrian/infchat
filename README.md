# InfChat

InfChat is an experimental open-source mobile chat app.

The mobile app is built with Expo, React Native, and Expo Router. The backend uses PocketBase for username-based authentication, profiles, friendships, conversations, and messages. The repository is organized as a pnpm monorepo with shared TypeScript packages and service directories for PocketBase and LiveKit-related infrastructure.

The App Store/TestFlight build is operated separately from any self-hosted forks of this open-source project. See `docs/apple/privacy-policy.md` for the privacy policy that applies to the distributed app.
